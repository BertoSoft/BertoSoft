* **Aplicaciones de Escritorio (C++ / Qt 6):** Interfaces gráficas modernas (QSS), arquitectura desacoplada (Modelo-Vista-Controlador), gráficos 2D/3D, control de procesos externos y visualización de datos en tiempo real sobre Linux y Windows.

* **Software Científico y Normativa Química:** Herramientas de cálculo molecular, espectroscopía IR, análisis de datos y automatización documental (REACH / CLP).
